One sentence, one wedding vow, spoken by a robot at its own wedding — funny and heartfelt at the same time. `main.py` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), deterministically, the same 163 characters every run:

> I vow to reboot beside you every morning, recharge your heart whenever it dips below twenty percent, and never update past the version of me you fell in love with.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
